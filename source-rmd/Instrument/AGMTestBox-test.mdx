<h1 id="part-instruments">(PART*) Instruments</h1>
<h1 class="unnumbered" id="agmtestbox">AGMTestBox</h1>
<h2 class="unnumbered" id="overview"><strong>Overview</strong></h2>
<p>Controls communication with the AGM DU Test Box.</p>
<h2 class="unnumbered"
id="sendagmpacket"><strong>SendAGMPacket</strong></h2>
<h3 class="unnumbered" id="header">Header</h3>
<p><code>int DLLEXPORT __stdcall SendAGMPacket(char *port, int baud, char *command, int command_size, char *status_message)</code></p>
<h3 class="unnumbered" id="purpose">Purpose</h3>
<p>Send a control packet to the AGM Test Box through an RS-232 COM port
and reads the response from the device.</p>

<h2 class="unnumbered"
id="ribvideocontrol"><strong>RIBVideoControl</strong></h2>
<h3 class="unnumbered" id="header-1">Header</h3>

<h3 class="unnumbered" id="purpose-1">Purpose</h3>
<p>Enables or disables the RIB video output on the AGM Test Box by
sending the appropriate control command the COM port.</p>

</tr>

<td><code>baud</code></td>
<td><code>int</code></td>
<td>Communication baud rate.</td>
</tr>

<h2 class="unnumbered"
id="agmpowercontrol"><strong>AGMPowerControl</strong></h2>
<h3 class="unnumbered" id="header-2">Header</h3>
<p><code>int DLLEXPORT __stdcall AGMPowerControl(char* state, int plug, char* IP_address, char *status_message)</code></p>
<h3 class="unnumbered" id="purpose-2">Purpose</h3>
<p>Controls the power state of the AGM Test Box through the WTI Power
Plug using an HTTP command.</p>
<h3 class="unnumbered" id="parameters-2">Parameters</h3>
<table>
<colgroup>
<col style="width: 18%" />
<col style="width: 10%" />
<col style="width: 70%" />
</colgroup>
<thead>
<tr>
<th>Parameter</th>
<th>Type</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>state</code></td>
<td><code>char*</code></td>
<td>Power state. Valid values are <code>"ON"</code>, <code>"OFF"</code>,
or <code>"BOOT"</code>.</td>
</tr>
<tr>
<td><code>plug</code></td>
<td><code>int</code></td>
<td>Plug number. Valid values are ‘3’ (Top AGM) or <code>4</code>
(Bottom AGM).</td>
</tr>
<tr>
<td><code>IP_address</code></td>
<td><code>char *</code></td>
<td>IP address of the WTI Power Plug.</td>
</tr>
<tr>
<td><code>status_message</code></td>
<td><code>char *</code></td>
<td>Stores the operation status or error message.</td>
</tr>
</tbody>
</table>

<td>Power command completed successfully.</td>
</tr>
<tr>
<td><code>1</code></td>

<tr>
<td><code>2</code></td>

</tr>

<td><code>3</code></td>

</tr>
</tbody>
</table>
