<h2 id="interfaceboxslot1hdlcwrapback">InterfaceBoxSlot1HDLCWrapBack</h2>
<h3 id="header">Header</h3>

`int DLLEXPORT __stdcall InterfaceBoxSlot1HDLCWrapBack(int vid, int pid, int value, char *status_message)`

<h3 id="purpose">Purpose</h3>

HW_BOX_Slot 1 HDLC wrap back.

<h3 id="parameters">Parameters</h3>

| Name | Type | Purpose |
|----|----|----|
| `vid` | `int` | HID device vid |
| `pid` | `int` | HID device pid |
| `value` | `int` | value must from 1 of (HS_TX_HS0, HS_TX_HS1, HS_TX_HS2, HS_TX_HS3) |
| `status_message` | `char *` | status msg |

<h3 id="return-values">Return Values</h3>

| Error Code | Error Description |
|------------|-------------------|
| `0` | Success |
| `-1` | Interface Box Slot 1HDLC Wrap Back initialization fail |
| `-2` | Interface Box Slot 1HDLC Wrap Back read failed |
| `-3` | Interface Box Slot 1HDLC Close DU Interface Box failed |
