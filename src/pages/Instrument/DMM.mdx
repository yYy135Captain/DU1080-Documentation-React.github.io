<h1 id="dmmc">DMM.c</h1>

<h2 id="overview">Overview</h2>
<h2 id="dmminitialize">DMMInitialize</h2>
<h3 id="header">Header</h3>

`int DLLEXPORT __stdcall DMMInitialize(char *resource_name, ViSession *dmm_handle, ViBoolean *test_result, char *status_message)`

<h3 id="purpose">Purpose</h3>

Initializes the digital multimeter.

<h3 id="parameters">Parameters</h3>

| Name             | Type          | Purpose                    |
|------------------|---------------|----------------------------|
| `resource_name`  | `char *`      | resource name              |
| `dmm_handle`     | `ViSession *` | address of dmm session     |
| `test_result`    | `ViBoolean *` | either VI_TRUE or VI_FALSE |
| `status_message` | `char *`      | string error message       |

<h3 id="return-values">Return Values</h3>

| Error Code | Error Description |
|----|----|
| `VI_SUCCESS` | niDMM initialized successfully |
| `!= VI_SUCCESS` | Error when calling InitWithOptions() or ConfigurePowerLineFrequency() |

<h2 id="dmmclose">DMMClose</h2>
<h3 id="header-1">Header</h3>

`int DLLEXPORT __stdcall DMMClose(ViSession dmm_handle, char *status_message)`

<h3 id="purpose-1">Purpose</h3>

Closes digital multimeter.

<h3 id="parameters-1">Parameters</h3>

| Name             | Type        | Purpose               |
|------------------|-------------|-----------------------|
| `dmm_handle`     | `ViSession` | address of dmm device |
| `status_message` | `char *`    | string error message  |

<h3 id="return-values-1">Return Values</h3>

| Error Code      | Error Description       |
|-----------------|-------------------------|
| `VI_SUCCESS`    | DMM closed successfully |
| `!= VI_SUCCESS` | DMM failed to close     |

<h2 id="dmmmeasure">DMMMeasure</h2>
<h3 id="header-2">Header</h3>

`int DLLEXPORT __stdcall DMMMeasure(ViSession dmm_handle, MeasurementType measurement_type, ViReal64 range, ViReal64 *reading, char *status_message)`

<h3 id="purpose-2">Purpose</h3>

Reads the DC Voltage at the given UUT pins with DMM and stores read value in Reading.

<h3 id="parameters-2">Parameters</h3>

| Name | Type | Purpose |
|----|----|----|
| `dmm_handle` | `ViSession` | address of dmm device |
| `measurement_type` | `MeasurementType` | enum that specifies measurement type |
| `range` | `ViReal64` | specifies minimum measurement val (frequency) or max measurement val (all other functions) |
| `reading` | `ViReal64 *` | measurement reading of dmm |
| `status_message` | `char *` | string error message |

<h3 id="return-values-2">Return Values</h3>

| Error Code      | Error Description             |
|-----------------|-------------------------------|
| `VI_SUCCESS`    | DMM was measured successfully |
| `!= VI_SUCCESS` | DMM failed to measure         |
