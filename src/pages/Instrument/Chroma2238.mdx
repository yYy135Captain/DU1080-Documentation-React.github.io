<h2 id="chroma2238initialize">Chroma2238Initialize</h2>
<h3 id="header">Header</h3>

`int DLLEXPORT __stdcall Chroma2238Initialize(char *port_name, long baud_rate, ViBoolean *test_result, char *status_message)`

<h3 id="purpose">Purpose</h3>

Initialize a VISA session on Chroma2238.

<h3 id="parameters">Parameters</h3>

| Name             | Type          | Purpose                         |
|------------------|---------------|---------------------------------|
| `port_name`      | `char *`      | string resource name            |
| `baud_rate`      | `long`        | rate of bit transmission (long) |
| `test_result`    | `ViBoolean *` | either VI_TRUE or VI_FALSE      |
| `status_message` | `char *`      | string error message            |

<h3 id="return-values">Return Values</h3>

| Error Code | Error Description                    |
|------------|--------------------------------------|
| `0`        | Initialization was successful        |
| `-1`       | Chroma2238 VISA failed to initialize |
| \`-2       | Chroma2238 failed to initialize      |
